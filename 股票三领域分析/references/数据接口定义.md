# 三接口数据接口定义

## 一、数据源约束

本框架假设唯一可用的数据源是 **腾讯行情 API**（`qt.gtimg.cn`），
因为其他数据源（东方财富、雪球、新浪财经）在当前环境中均不可用。

| 数据 | 可用源 | 降级策略 |
|---|---|---|
| 行情/K线 | 腾讯行情 API | 无可降级，必须用此源 |
| 资金流向 | westock CLI 或手动输入 | 若无 westock，需手动提供数据 |
| 筹码分布 | westock CLI 或手动输入 | 同上 |
| 板块排行 | westock CLI 或手动输入 | 同上 |
| 财务数据(PE/PB/股息) | 手动输入或财报解析 | 必须提供，无自动源 |

> **重要**：腾讯行情 API 返回的是**逐股文本**，不是结构化 JSON。
> 解析时需按字段索引取值。

## 二、腾讯行情 API 格式

### 2.1 请求格式

```
https://qt.gtimg.cn/q=600036,601398,601288
```

一次最多取 **60 个**股票代码，超出需分批。

### 2.2 返回格式（示例）

```
v_sh600036="1~招商银行~600036~42.93~42.63~42.50~328445~290149~38296~328444~245678~
 156789~...~42.93~42.63~42.50~43.10~42.30~41.80~42.50~...~-0.30~-0.70~..."
```

### 2.3 字段索引对照

| 索引 | 字段 | 单位 | 说明 |
|---|---|---|---|
| 0 | 市场 | — | 1=SH, 0=SZ |
| 1 | 名称 | — | 例：招商银行 |
| 2 | 代码 | — | 例：600036 |
| 3 | 现价 | 元 | T 日收盘价或实时价 |
| 4 | 昨收 | 元 | T-1 日收盘价 |
| 5 | 今开 | 元 | T 日开盘价 |
| 6 | 成交量 | 手 | T 日成交量 |
| 7 | 外盘 | 手 | 主动买入 |
| 8 | 内盘 | 手 | 主动卖出 |
| 17 | 最高 | 元 | T 日最高价 |
| 18 | 最低 | 元 | T 日最低价 |
| 30 | 日期时间 | — | 例：20261113150000 |
| 31 | 涨跌额 | 元 | 现价 - 昨收 |
| 32 | 涨跌幅 | % | (现价-昨收)/昨收×100 |
| 33 | 总额 | 万元 | T 日总成交额 |
| 34 | 总量 | 手 | 同成交量 |
| 37 | 换手率 | % | 成交量/流通股本×100 |
| 39 | 市盈率-动态 | — | PE_TTM（注意：部分股票可能为空） |
| 40 | 市净率 | — | PB |
| 41 | 总市值 | 万元 | — |
| 42 | 流通市值 | 万元 | 用于计算净流入率 |

### 2.4 解析示例（PowerShell）

```powershell
$url = "https://qt.gtimg.cn/q=sh600036"
$body = Invoke-WebRequest -Uri $url -UseBasicParsing
# 提取 v_sh600036= 后面的字符串，按 ~ 分割
$lines = $body.Content -split "`n" | Where-Object { $_ -match '^v_sh600036=' }
$vals = $lines[0] -replace '^v_sh600036="(.*)"$', '$1' -split '~'
$price = [double]$vals[3]     # 现价
$pe    = [double]$vals[39]    # PE_TTM
$pb    = [double]$vals[40]    # PB
$float_cap = [double]$vals[42] # 流通市值(万元)
```

## 三、资金面接口 — 手动取数

### 3.1 当 westock 不可用时

资金流向数据（逐日）：

| 字段 | 说明 | 获取方式 |
|---|---|---|
| `main_net_flow` | 主力净流入 | 手动输入或行情软件导出 |
| `super_large_net` | 超大单净流入 | 同上 |
| `large_net` | 大单净流入 | 同上 |
| `total_amount` | 总成交额 | 腾讯行情 API 字段 33 |
| `float_market_cap` | 流通市值 | 腾讯行情 API 字段 42 |
| `sector_main_flow` | 板块主力净流入 | 手动输入 |

### 3.2 派生字段计算

```python
# N日累计净流入率
main_net_rate_Nd = (sum(N_days.main_net_flow) / sum(N_days.total_amount)) * 100

# 板块排名百分位
rank_pct = (sector_rank - 1) / (total_constituents - 1)
```

### 3.3 判定逻辑速查

| L级 | 条件 | 结果 |
|---|---|---|
| L0 | 窗口覆盖 ≥ 80% | 通过，否则 INSUFFICIENT_DATA |
| L1 | 3d,5d,10d rate > 0 且 20d rate ≥ 0 | 通过，否则 FAIL |
| L2 | 5d rate ≥ 1.5% 且 10d rate ≥ 1.0% | PASS，否则 WEAK |
| L3 | 板块排名前 10% | 不降级 |
| L4 | 大单+超大单净流入 > 0 且 中小单净流出 | 保持 PASS |
| L4 | 大单净流出 且 小单净流入 | PASS 降 WEAK |

## 四、技术面接口 — 手动取数

### 4.1 必需数据

日 K 线（至少 260 个交易日）：

| 字段 | 来源 | 精度 |
|---|---|---|
| open | 腾讯 K 线 API | 元，两位小数 |
| high | 同上 | 同上 |
| low | 同上 | 同上 |
| close | 同上 | 同上 |
| volume | 同上 | 手 |
| amount | 同上 | 万元 |

### 4.2 指标计算

```python
# 均线
MA5  = sum(close[-5:]) / 5
MA10 = sum(close[-10:]) / 10
MA20 = sum(close[-20:]) / 20
MA60 = sum(close[-60:]) / 60
MA120 = sum(close[-120:]) / 120

# RSI(6)
delta = close - close.shift(1)
gain = delta.where(delta > 0, 0).rolling(6).mean()
loss = (-delta).where(delta < 0, 0).rolling(6).mean()
RSI6 = 100 - 100 / (1 + gain / loss)

# KDJ(9)
# RSV = (close - LLV(low, 9)) / (HHV(high, 9) - LLV(low, 9)) * 100
# K = SMA(RSV, 3, 1)
# D = SMA(K, 3, 1)
# J = 3*K - 2*D

# ATR(14)
TR = max(high-low, abs(high-pre_close), abs(low-pre_close))
ATR14 = TR.rolling(14).mean()

# MACD
EMA12 = EMA(close, 12)
EMA26 = EMA(close, 26)
DIF = EMA12 - EMA26
DEA = EMA(DIF, 9)
MACD = 2 * (DIF - DEA)

# 布林带
BOLL_mid = MA20
BOLL_upper = MA20 + 2 * std(close[-20:])
BOLL_lower = MA20 - 2 * std(close[-20:])
```

### 4.3 判定逻辑速查

| L级 | 条件 | 结果 |
|---|---|---|
| L0 | close > MA60 且 close > MA120 | BULL_ALIGNED |
| L0 | close < MA20 且 close < MA60 | BEAR_STRUCTURE → FAIL |
| L0 | 其他 | SHORT_REPAIR（×0.7） |
| L1 | 3项确认全通过 | 系数 1.0 |
| L1 | 2项确认通过 | 系数 0.7 |
| L1 | 1项确认通过 | 系数 0.5 |
| L1 | 0项确认 | 系数 0.3 → FAIL |
| L2 | RSI6 < 70 且 KDJ_J < 80 | 无惩罚 |
| L2 | 否则 | 系数 × 0.5 |

## 五、安全垫接口 — 数据字段

### 5.1 必需字段

| 字段 | 来源 | 说明 |
|---|---|---|
| `PE_TTM` | 腾讯行情 API 字段 39 | 动态市盈率 |
| `PE_industry_median` | 手动输入 | 行业中位数 PE |
| `PB` | 腾讯行情 API 字段 40 | 市净率 |
| `dividend_yield` | 手动输入/财报 | 股息率（%） |
| `avg_cost` | westock chip 或手动 | 筹码均价 |
| `profit_ratio` | westock chip 或手动 | 获利盘占比（%） |
| `net_profit_yoy` | 财报 | 归母净利润同比（%） |
| `gross_margin_trend` | 财报 | 毛利率趋势（上升/持平/下降） |

### 5.2 行业中位数获取（手动）

```
方法 1: 东方财富行业板块页面查看行业中位数 PE/PB
方法 2: 选股软件导出行业成分股 PE 排序取中位数
方法 3: 自行计算申万二级行业成分股 PE 中位数
```

### 5.3 判定逻辑速查

| L级 | +1 条件 | -1 条件 |
|---|---|---|
| L1 估值 | PE_TTM < 行业中位数×0.8 | PE_TTM ≥ 行业中位数×1.5 |
| L2 股息 | dividend_yield ≥ 3% | dividend_yield < 1% |
| L3 筹码 | profit_ratio > 60% 且 close > avg_cost | profit_ratio < 30% 且 close < avg_cost×0.9 |
| L4 盈利 | net_profit_yoy > 10% 且毛利上升/持平 | net_profit_yoy < 0 且毛利下行 |

**总分范围：-4 ~ +4**

| 总分 | 等级 |
|---|---|
| ≥ 2 | THICK |
| 0~1 | MODERATE |
| -1~-2 | THIN |
| ≤ -3 | NO_MARGIN |

## 六、降级与标记策略

当数据不可用时，按以下规则降级：

| 数据缺失 | 处理方式 |
|---|---|
| 任一资金窗口覆盖 < 80% | 该接口 → INSUFFICIENT_DATA，整体 → 不判定 |
| 腾讯行情 API 不可用 | 标记 `DATA_UNAVAILABLE`，不执行分析 |
| 行业中位数未知 | 跳过 L1 估值判定，得分记为 0 |
| 股息率未知 | 跳过 L2 股息判定，得分记为 0 |
| 财报数据更新中 | 使用最新可用财报（标注"数据截止日"） |
| 筹码数据缺失 | 跳过 L3 筹码判定，得分记为 0 |
| 一致预期数据缺失 | L5 记为 0（可选因子，不影响核心判定） |

**降级汇总**：
- 降级 ≤ 2 项 → 结论标记 `CONDITIONAL`
- 降级 ≥ 3 项 → 结论标记 `INSUFFICIENT_DATA`，不进入最终判定
